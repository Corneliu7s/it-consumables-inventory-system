# Automated IT Consumables Inventory & Stock Tracking System

A web-based relational database platform designed to automate storeroom operations, secure item checkouts, prevent stockouts, and maintain real-time inventory balances.

## 🚀 Key Features
- **Dashboard Overview:** Displays active item totals, low-stock threshold alerts, and recent transaction records.
- **Item Cataloging:** Classifies hardware accessories, sets minimum inventory boundaries, and manages stock units.
- **Staff Directory:** Maintains records of authorized staff members and departments eligible for item issuances.
- **Atomic Transactions:** Executes real-time stock deductions on issue and stock increments on restock/return.

## 🛠️ Tech Stack
- **Backend:** PHP 8.2 (PDO MySQL / SQLite)
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Environment:** Termux / XAMPP Local Server Architecture
